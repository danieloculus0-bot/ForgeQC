# Local imports

Place private local workbooks here when running ForgeQC on your own machine.

Expected legacy RMA tracker filename:

`RMA_Tracker.xlsx`

Expected workbook format only:

- Sheet: `RMA Log`
  - Date
  - Order Number
  - Customer
  - Department
  - Person
  - Defect Description
  - Reason Code
- Sheet: `Customer List`
- Sheet: `Reason Codes`
- Sheet: `Department List`

Do not commit real customer names, RMA events, defect logs, or proprietary workbook files to this public repository.
